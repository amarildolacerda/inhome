# Project Manager

Sistema de gestão de projetos para equipes que precisam organizar tarefas, acompanhar progresso e manter tudo em um só lugar.

## O que é

O **Project Manager** é uma aplicação web que ajuda você a:

- **Criar e gerenciar projetos** com descrição, status e progresso
- **Organizar tarefas** com prioridades, responsáveis e prazos
- **Acompanhar o progresso** através de um dashboard com métricas
- **Trabalhar em tempo real** com notificações instantâneas

## Para quem é

- Times pequenos e médios que precisam de controle simples
- Gerentes de projeto que querem visão clara do progresso
- Equipes distribuídas que precisam de colaboração em tempo real

## Como funciona

### Dashboard
Veja de relance:
- Projetos ativos
- Tarefas pendentes e concluídas
- Prioridades urgentes
- Taxa de conclusão

### Projetos
- Crie projetos com nome e descrição
- Acompanhe quantas tarefas estão pendentes
- Visualize o progresso de cada projeto

### Tarefas
- Organize por prioridade (baixa, média, alta, urgente)
- Atribua responsáveis
- Mova pelo fluxo: A Fazer → Em Progresso → Revisão → Concluído

## Acesso

1. Crie sua conta com email e senha
2. Faça login para acessar seus projetos
3. Comece criando seu primeiro projeto
